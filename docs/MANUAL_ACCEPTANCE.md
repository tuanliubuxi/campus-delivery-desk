# V1 人工设备验收清单

自动测试不能代替真实设备的安装、触控、相机和浏览器行为。本清单只记录实际执行结果；未执行的项目不得在实施进度中标为完成。

## Android 真机

- [ ] 使用正式 HTTPS 域名打开系统，浏览器未显示证书错误。
- [ ] 浏览器提供“安装应用”，安装后从桌面图标以 standalone 模式启动。
- [ ] 360px 左右视口无页面级横向溢出，主要按钮触控区域可用。
- [ ] 配送员登录、切换业务、接单、取件、配送完成、上传相机照片流程可用。
- [ ] 配送完成可提交成功；圆圈/方框/直线仅在拖拽后生成，颜色、粗细、撤销、清空和保存均可用。
- [ ] 选择远景照片后才出现“标记远景照片”；点击打开遮罩弹框，取消、Esc 或点击遮罩不保留未保存笔画，保存后标注图随配送证据上传。
- [ ] 浏览器切到后台超过 150 秒再返回时，同一会话可恢复；被其他设备接管或管理员强制下线后旧会话不可恢复。
- [ ] 上传过程中断网时表单和已选图片仍保留，联网后可直接重试且不重复完成。
- [ ] 断网状态提示清晰，不允许用户误以为业务已经离线提交。
- [ ] 四套主题可读，暗色主题表单、表格与提示对比度正常。
- [ ] 普通/代理活跃订单的“我的任务”均正常打开；长名称与备注不撑破卡片，完整内容可在详情查看。
- [ ] 四套主题下“我的归拢”、代理批次和结算空状态提示的背景、文字对比度正常。
- [ ] 底部分类栏不遮挡内容，顶部账号、主题和退出始终可见且二级菜单能横向滚动。

## Windows 管理员/录单员

- [ ] 1366px 宽屏导航、表格、Dashboard、配置、结算和备份页面可用。
- [ ] 宽屏分组导航的当前分类和当前功能保持高亮，人员在线指示会随心跳变化。
- [ ] 360px 窄屏模拟下无页面级横向溢出，表格在局部容器内滚动。
- [ ] PWA 可安装并从开始菜单/桌面启动。
- [ ] 录单文本草稿刷新后恢复，成功提交后清除。
- [ ] 重复点击关键提交按钮不会产生重复业务记录。
- [ ] 开发者工具没有 jsDelivr/外部前端 CDN 请求或跟踪防护警告。
- [ ] 操作成功、业务拒绝及数据库忙提示在全屏遮罩弹框中可见，关闭、Esc 和点击遮罩行为正常；字段错误仍指向具体输入框。
- [ ] 经营分析首次打开为当天筛选，清空后可看全部历史，导出 Excel 与当前筛选一致；工资和新建日期控件默认本地当天。
- [ ] 登录长名称下拉项、人员/客户/代理及系统日志表格在宽窄屏下均不撑破布局。
- [ ] 结算草稿只有一名最终配送员时“最终受益人”默认选中此人；多名配送员时留空要求人工确认，超长姓名在下拉项中省略并能查看完整姓名。

## 配送员桌面布局

- [ ] Windows 桌面浏览器打开配送员页面时，业务内容仍居中限制在约 420～480px。
- [ ] 不出现仅桌面端的另一套配送表格工作流。
