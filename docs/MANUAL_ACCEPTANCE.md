# V1 人工设备验收清单

## v0.4.0 现场复核

- [ ] 六类业务录单：服务日期默认当天；校外目的地、校外取件区间、其他取餐地点按选择显示并校验；上楼与加急在配送员任务中可见。校外上楼提交前提示不自动计楼层费，校外行李按配置基础费起算，人工附加服务费归属最终配送员。
- [ ] 每次真实配送均可填写说明；归拢后录单员结算能按配送员姓名、订单及时间看到前序配送说明，不将多单共同放置误作多次备注。
- [ ] 异常直接上传、已有配送证据、已有归拢图片各最多四张；实际文件已清理的证据不能引用或下载。媒体页可按类型、状态筛选并按日期、大小排序，大图在弹框内滚动。
- [ ] 薪资工作台默认显示最近十条待核算／草稿／待发放记录，可按人、日期、状态筛选；同日补发显示第几次。配送员只见本人待发放／已发放记录，默认最近十条，工作年份和月份来自实际完成订单。
- [ ] 核算与实际发放是两次明确操作；管理员待发放工资条及双方已发放工资条可预览和下载卡片／正式两种动态样式，不能访问他人的工资条，作废草稿不能下载。
- [ ] 发薪记录、我的薪资、订单历史和媒体管理长列表有滚动高度与分页；窄屏操作不被滚动容器裁切。订单历史展示业务常用信息，经营分析继续承担高级筛选与统计，内部目的地区域代码不得直接显示。
- [ ] 人员创建账号在弹框内，计薪比例可明确选择继承默认或单独设定且显示有效值；系统规则按类型分色分组并在窄屏保持可用。
- [ ] 代理临时收件人的配送凭证和结算凭证分别重建、分别查看版本；超过三版时最旧文件被清理但元数据留存，不能错把一种凭证替换为另一种。
- [ ] 订单详情时间线每项操作显示操作人员；对历史缺失操作者的记录明确显示“操作人未记录”。

## v0.3.9 增量修正复核（覆盖本地 0.3.9 包）

- [ ] 代理人仍有录入中或待结算批次时无法停用；仅全部批次已结算或已取消后开关可关闭，重新启用后可新建批次。
- [ ] 客户疑似重复必须先显示候选客户，未经确认不得保存；从客户卡片发起录单时不带入上一次草稿，刷新本次录单仍可恢复。
- [ ] 完成配送的共同放置订单为清晰的勾选卡片，显示收件人、业务、目的地和次要订单号，不再出现空白圆角条。
- [ ] 亮、暗、暖、蓝青主题的收件归属、位置、取件标识、费用色块和焦点／选中／禁用状态可辨；配送凭证的关键文字色块清晰、照片不被挤小。
- [ ] 订单历史与代理收件人凭证弹框中可展开有权限的原始证据；证据已清理时显示提示，不留下坏图。

## v0.3.9 发布后复核

- [ ] 录单页从客户卡片进入后加载所选客户而非上一次草稿；搜索客户按钮与输入框并排。新建订单不会永久改动客户资料，疑似重复客户会在保存前提示。
- [ ] 外卖／KFC／果蔬勾选上楼后，录单员可留空件数；配送员完成前须确认独立袋／箱／包件数。已有件数不重复询问；整单总费用建议及理由在结算页可采纳或保留公式价。
- [ ] 配送员可混接非快递简单业务，但接快递期间不能混接；窄屏“接新任务”可达，任务卡片可按业务辨识。只有远景标注图时也能完成配送。
- [ ] 建立异常时选择常见类型或“其他”；配送证据／归拢证据分别按日期和任务筛选、各最多选四张，已选图片能移除；内部编号不作为主要名称。
- [ ] 管理员按配送员、工作日核算薪资：订单收款已确认才计入，未完成任务阻止核算；调整后总额须大于零；核算草稿与实际发放分开。管理员历史和配送员“我的薪资”均可筛选并查看逐项明细。
- [ ] 结算历史独立筛选、查看及返回；订单详情和凭证弹框的关键信息在明暗主题均醒目。凭证弹框可查看权限内原始证据；媒体下载不跳离当前页。

## v0.3.8 发布后复核

- [ ] 管理员修改凭证显示名称及图片质量后，新凭证标题更新、旧凭证不变；用真机拍取件码分别比较三档的清晰度、上传速度和文件大小。
- [ ] 多件快递的客户凭证和代理汇总逐件列取件标识；归拢后的凭证位置为归拢最终位置，近景照片单列大图纵排且可看清关键标签。
- [ ] 找件清单同一收件人只显示一次主要信息，但每件的取件标识、原位置、照片与三个找件结果仍可独立操作。
- [ ] 订单列表代理色块、订单详情“查看所属批次”和批次页返回订单入口正常；被清理或文件已不存在的凭证无查看按钮。
- [ ] 录单员在同轮有其他订单未完成时，看见明确的等待提示；现场复验“找到”并记录请求结果和容器日志。

## v0.3.7 发布后复核

- [ ] 找件清单逐件点击“找到／客户已取／人工处置”：找到直接记录；后两者要求填写依据／原因，取消不改状态；人工处置生成可追踪异常。
- [ ] 找到实物后，最终位置与 1–4 张近景合照必填；第 5 张被拒绝；远景可选，标注弹框的撤销、清空、取消和保存正常，选错照片可从列表移除。
- [ ] 全部物件为客户已取或人工处置时，不出现最终照片／位置必填提示，也不保存虚构凭证；弱网重试不重复完成同一轮。

## v0.3.6 发布后复核

- [ ] 同一快递轮次的全部物件在同一次 DeliveryDrop 共用位置与照片时直接关闭，不再出现重复找件清单；不同 Drop 仍创建必要归拢。
- [ ] 找件清单优先显示收件人、微信、手机尾号、取件标识和备注；“客户已取”“人工处置”点击后出现结果弹框并确实改变状态。
- [ ] 代理临时收件人的配送凭证只在全部送达且归拢完成后可创建，图中无价格；冻结结算后可查看独立结算凭证。
- [ ] 普通录单与完成补录可搜索客户、按楼栋找客户并预填地址；快速完成和历史补录的照片/说明要求在页面上可读，返回按钮回到业务选择。
- [ ] 配送员任务页“待归拢”数量与我的归拢一致；订单详情时间线只显示实际留有记录的节点。

## v0.3.5 发布后复核

- [ ] 录单员结算页按快递轮次和代理批次显示整组订单：同组只有一个勾选框、成员同底色；一次不能跨组建立草稿。归拢与异常证据的多选操作明确显示各自选择范围。
- [ ] 已结算账单的追加退款和撤销操作先打开遮罩弹框，取消及点击框外均不提交；长配送员姓名不撑破下拉框。
- [ ] 订单列表、结算详情和代理批次的有效凭证在弹框中预览与下载；手机可双指缩放，电脑可用浏览器缩放。删除最新凭证后显示上一可用版本，没有可用版本时不显示入口。
- [ ] 代理批次录入中时能看见尚缺条件；条件全部满足后自动进入待结算。管理员配置页显示实际自动备份时间。
- [ ] 系统日志的快递大小说明／价格建议事件及业务配置、站点配置、维护状态对象显示中文名称，内部代码仍可在详情中核对。

自动测试不能代替真实设备的安装、触控、相机和浏览器行为。本清单只记录实际执行结果；未执行的项目不得在实施进度中标为完成。

## Android 真机

- [ ] 使用正式 HTTPS 域名打开系统，浏览器未显示证书错误。
- [ ] 浏览器提供“安装应用”，安装后从桌面图标以 standalone 模式启动。
- [ ] 360px 左右视口无页面级横向溢出，主要按钮触控区域可用。
- [ ] 配送员登录、切换业务、接单、取件、配送完成、上传相机照片流程可用。
- [ ] 配送完成可提交成功；圆圈/方框/直线仅在拖拽后生成，颜色、粗细、撤销、清空和保存均可用。
- [ ] 选择远景照片后才出现“标记远景照片”；点击打开遮罩弹框，取消、Esc 或点击遮罩不保留未保存笔画，保存后标注图随配送证据上传。
- [ ] 浏览器切到后台超过 150 秒再返回时，同一会话可恢复；被其他设备接管或管理员强制下线后旧会话不可恢复。
- [ ] 上传过程中断网时表单和已选图片仍保留，联网后可直接重试且不重复完成。
- [ ] 断网状态提示清晰，不允许用户误以为业务已经离线提交。
- [ ] 四套主题可读，暗色主题表单、表格与提示对比度正常。
- [ ] 普通/代理活跃订单的“我的任务”均正常打开；长名称与备注不撑破卡片，完整内容可在详情查看。
- [ ] 四套主题下“我的归拢”、代理批次和结算空状态提示的背景、文字对比度正常。
- [ ] 底部分类栏不遮挡内容，顶部账号、主题和退出始终可见且二级菜单能横向滚动。
- [ ] 手机 Edge 中上下滚动“我的任务”和异常长列表时，顶栏固定且不盖住正文；底栏位置不变。
- [ ] 未知大小订单提交时必须在遮罩弹框选实际大小，点击遮罩和系统返回键不能略过；已知大小可修正并填写建议，近景照片照常上传。
- [ ] cpolar/移动网络在状态预检时中断后，页面仍尝试上传；失败时保留照片和输入、恢复后用相同操作编号重试，不能重复完成。
- [ ] 同客户跨多个任务仅见一个“处理这组订单”入口，弹框里仍能进入每个独立任务；状态指示灯可区分待取、已取和配送中。

## Windows 管理员/录单员

- [ ] 1366px 宽屏导航、表格、Dashboard、配置、结算和备份页面可用。
- [ ] 宽屏分组导航的当前分类和当前功能保持高亮，人员在线指示会随心跳变化。
- [ ] 360px 窄屏模拟下无页面级横向溢出，表格在局部容器内滚动。
- [ ] PWA 可安装并从开始菜单/桌面启动。
- [ ] 录单文本草稿刷新后恢复，成功提交后清除。
- [ ] 重复点击关键提交按钮不会产生重复业务记录。
- [ ] 开发者工具没有 jsDelivr/外部前端 CDN 请求或跟踪防护警告。
- [ ] 操作成功、业务拒绝及数据库忙提示在全屏遮罩弹框中可见，关闭、Esc 和点击遮罩行为正常；字段错误仍指向具体输入框。
- [ ] 经营分析首次打开为当天筛选，清空后可看全部历史，导出 Excel 与当前筛选一致；工资和新建日期控件默认本地当天。
- [ ] 登录长名称下拉项、人员/客户/代理及系统日志表格在宽窄屏下均不撑破布局。
- [ ] 结算草稿只有一名最终配送员时“最终受益人”默认选中此人；多名配送员时留空要求人工确认，超长姓名在下拉项中省略并能查看完整姓名。
- [ ] 录单员登录进入订单页；创建订单时客户不可留空、服务日期显示今日，其他必填项仍有字段级提示。
- [ ] 添加结算级费用与废弃账单均按需弹框，唯一关联对象默认选中；已作废账单打开可读到作废原因，价格建议不会自行改变收费。
- [ ] 异常页建立/筛选弹框可关闭，待处理和已处理双栏独立滚动；窄屏仅显示当前状态列表且可切换。
- [ ] 配送员统计筛选弹框可取消；待出账、待客户付款、已付款收益归属和计薪参考文案不会被误读为已发工资。
