# 06. 页面、交互、UI 与 PWA

## 1. 布局策略

### 管理员/录单员

- 宽屏：桌面表格、双栏/三栏 Dashboard；
- 窄屏：手机卡片、折叠筛选器；
- 使用 CSS media queries/Bootstrap breakpoints，不依赖 UA 判断作为唯一依据。

### 配送员

只设计移动端任务流。即使桌面打开，也在页面中央显示约 420～480px 的移动卡片容器，不为配送员另做桌面表格工作流。

## 2. 主题

至少 4 套：

- Light 亮色；
- Dark 暗色；
- Warm 暖色；
- Fresh Blue/Cyan 清爽蓝青。

通过 CSS Variables 实现；用户可选，管理员配置默认主题。不做任意颜色编辑器。

## 3. 登录页

普通：角色 → 人员下拉 → 密码。

fresh active lease 存在时显示：“该账号当前正在其他设备使用”。不要提供普通用户“强制挤下线”按钮。

管理员后台可强制下线。

前端启动后每约 30 秒 heartbeat；多标签共享 Session。

## 7. 快递录单 UI

字段：收件归属、pickup_area 单选（南/北/校外）、OUTSIDE 具体地点、取件标识类型/内容、大小（含未知）、路线/客户直送、目的地、是否上楼、加急、备注。

校内送校外：选择“校外地址”后显示详细地址文本框。

UNKNOWN 大小时显示“基础价待配送员确认”。

## 8. 代理单录入 UI

流程建议：

```text
选择/新建 Agent
→ 新建 ProxyBatch
→ 新建临时收件人
→ 连续给该收件人添加快递
→ 切换/新增下一个临时收件人
```

临时名支持一键生成 `15号楼#1`。

列表应清楚显示：每个临时收件人有几件、楼栋、取件区域和状态。OPEN 批次在不存在已 PICKED/DELIVERING/DELIVERED 有效快递时可显示“取消整批”，二次确认后由后端原子取消仍未取件订单并关闭相关全取消 ExpressRound，不要求用户逐单取消。若已有实际取件/配送/完成订单则隐藏或禁用整批取消并说明原因。ProxyBatch 处于 READY_TO_SETTLE 时默认冻结新增操作，并提供仅录单员/管理员可见的“重新打开批次”；READY_TO_SETTLE/SETTLED 均不允许整批取消，SETTLED 后不允许追加。

## 9. 配送凭证 UI

配送完成页：

```text
近景照片 [推荐/普通业务至少一张总证据]
远景照片 [推荐]
[标记远景位置]
最终位置 *
备注
```

如果只有一张，弹非阻塞提醒：建议补充远景，用户仍可继续提交。

标记工具只需：圆圈/箭头/自由画笔（可选实现其一到两个）、撤销、清空、保存。

## 10. 归拢 UI

先显示每件原照片 + 原位置 + [找到]。全部 FOUND/人工处置后进入最终拍照。

最终建议：近景合照 + 远景标注 + 最终位置。

## 11. 费用项结算 UI

结算页不提供“直接改总价”。显示：

```text
基础费用
系统附加费
[ ] 特殊天气（按当前收件归属/结算轮计一次）
[ ] 本轮多件优惠
[+ 客户自愿加价]
[+ 其他增费]
[+ 减免]
----------------
应收总额
```

每次调整都产生或逻辑作废 ChargeItem，不直接改总价。DRAFT 阶段允许编辑这些费用项；结算时新增的天气、客户自愿加价、人工增减、多件优惠必须绑定当前 Settlement，快递天气/多件优惠同时记录对应 ExpressRound。费用项录错时使用 VOIDED，不物理删除。若实时预览总额小于 0，界面必须明显警告且禁止生成有效结算凭证；0 元允许。

若本轮存在多个最终配送员，添加“客户自愿加价”时必须选择收益归属配送员；给多人加价时添加多条。

[生成有效结算凭证] 才会冻结 SettlementLine 并进入 WAITING_PAYMENT；生成前可预览。DRAFT/未付款账单还应提供 [废弃账单]，按规则标记 VOIDED 后重建。

## 12. 代理图片 UI

ProxyRecipient：

```text
[ ] 凭证显示价格（默认勾选）
[预览客户凭证]
[下载]
```

ProxyBatch：

```text
[生成代理汇总结算图]
[下载全部客户凭证]  # 可做逐张，也可后续 zip
```

代理汇总图不得包含客户照片。

## 13. 工资计算器 UI

模式切换：比例 / 手工。

手工模式实时显示：已结算净服务收入池、强制归属金额、剩余可人工分配金额、当前人工合计。强制归属金额不可转给其他成员；人工合计超出剩余池立即红色阻止提交；个人最终金额超过本人普通配送收益只黄字提醒。

## 14. 多维 Dashboard

顶部可折叠筛选区。桌面横向布局，手机用“筛选”抽屉。

所有卡片、图表、表格、导出统一应用当前筛选。

## 15. PWA 与弱网

- 可安装到 Android/Windows 桌面；
- 不做离线业务处理；
- 网络断开显示明确状态；
- 文本表单可 localStorage 暂存；
- 图片压缩后可在页面内保留重试引用；
- 上传/提交失败不得清空表单。

## 16. 图片压缩

浏览器端建议：最长边 1920px、WebP quality 0.82 左右；服务端再次校验并生成缩略图。移除 EXIF/GPS。

## 17. 可访问性/交互底线

- 主要按钮触控区域 >= 44px；
- 配送页单手可操作；
- 360px 宽不横向溢出；
- 暗色主题对比度可读；
- loading/disabled 防重复点击；
- 错误信息必须指出可修复原因。
